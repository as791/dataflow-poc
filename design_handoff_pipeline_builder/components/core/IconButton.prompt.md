IconButton — compact 36×36px icon-only control (`.icon-button`), used in the sidebar nav rail, drawer header, and toolbar corners (refresh, theme toggle, close).

```jsx
<IconButton title="Refresh"><RefreshIcon /></IconButton>
<IconButton title="Pipelines" active><WorkflowIcon /></IconButton>
```

`active` switches to the brand-tinted selected state used for the current nav route.
